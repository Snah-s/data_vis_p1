# data_vis_p1

## GraphletMatchMaker D3 Visualizations

This project includes a D3/Vite web app that recreates the main visual analysis views from `GraphletMatchMaker.pdf`:

- node-link template vs candidate comparison,
- graphlet frequency heatmap,
- temporal profile view by activity layer,
- node/profile matching distance heatmap,
- Q2 seed inspection,
- final candidate ranking.

### Run Locally

```bash
npm install
npm run data
npm run dev
```

Open the URL printed by Vite, usually `http://localhost:5173`.

### Build

```bash
npm run build
```

The build regenerates `public/data/graphletmatchmaker.json` from the CSV files before bundling the app into `dist/`.

### Data Generation

The static JSON used by D3 is generated by:

```bash
micromamba run -n vast2020 python scripts/generate_d3_data.py
```

The generator computes graph summaries, graphlet frequencies, temporal profiles, profile distances, seed inspection, and candidate ranking.
